# XSafety

Локальный статический сканер файлов: проверяет содержимое **без запуска**,
показывает находки с серьёзностью и рекомендациями и считает суточные лимиты
по тарифам.

- 127 сигнатур + структурные проверки архивов и PE;
- 4 модели с разными наборами расширений;
- тарифы Default / Pro / Premium с суточными квотами и демо-оплатой;
- HTML-отчёт по каждой проверке, история последних 100 отчётов;
- тёмный интерфейс без внешних зависимостей.

> Демо-режим оплаты: тариф активируется сразу, деньги не списываются.

---

## Модели и расширения

| Модель | Расширения | Где доступна |
|---|---|---|
| **XSafety 1** | `.bat`, `.py` | default, pro, premium |
| **XSafety 2** | всё из 1 + `.js`, `.ps1` | pro, premium |
| **XSafety 3 Lite** | всё из 2 + `.vbs`, `.hta`, `.dll`, `.zip` | pro, premium |
| **XSafety 3 Pro** | всё из 3 Lite + `.exe`, `.jar` | premium |

`.cmd`, `.pyw`, `.mjs`, `.vbs`, `.psm1` и т.п. проверяются вместе с основным
расширением модели.

## Суточные лимиты

Окно — календарные 24 часа UTC (сброс в 00:00 UTC). У каждой модели свой
счётчик запросов и объёма.

| Тариф | XSafety 1 | XSafety 2 | 3 Lite | 3 Pro |
|---|---|---|---|---|
| **Default** | 10 запросов · 10 МБ | — | — | — |
| **Pro** | 20 · 30 МБ | 10 · 30 МБ | 1 · без лимита МБ | — |
| **Premium** | 30 · без лимита МБ | 20 · без лимита МБ | 15 · без лимита МБ | 10 · без лимита МБ |

Модель, которой нет в тарифе, **не получает новых лимитов каждые 24 часа**:
в API это `available: false`, `blocked: true`, `refill_scheduled: false`, а в
интерфейсе — «не входит в тариф». Это не «серая» модель с лимитом, а
полное отсутствие доступа.

Для тарифов без лимита МБ действует технический потолок загрузки — 64 МБ.

## Цены и скидки

Скидка считается на сервере из пары «старая цена → новая цена» и никогда
не принимается от клиента.

| Тариф | 7 дней | 1 месяц | Навсегда |
|---|---|---|---|
| **Pro** | 89 грн ~~129~~ · **−31%** | 249 грн ~~420~~ · **−40,7%** | 1299 грн ~~2900~~ · **−55,2%** |
| **Premium** | 175 грн ~~200~~ · **−12,5%** | 499 грн ~~700~~ · **−28,7%** | 1699 грн ~~1700~~ · **−0,06%** |

Продление того же тарифа добавляет срок к текущей дате окончания; смена
тарифа начинается с текущего момента.

## Быстрый старт

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python -m xsafety
# http://localhost:8000
```

Для тестов:

```bash
pip install -r requirements-dev.txt
python -m pytest -q
```

## API

Все ошибки — `{"error": {"code", "message", "details"}}`.
Изменяющие запросы требуют заголовок `X-CSRF-Token`, равный cookie `xsafety_xsrf`.

| Метод | Путь | Описание |
|---|---|---|
| `GET` | `/api/health` | версия и период лимитов |
| `GET` | `/api/plans` | тарифы, цены, скидки, модели |
| `POST` | `/api/auth/register` | регистрация + сессия |
| `POST` | `/api/auth/login` | вход + сессия |
| `POST` | `/api/auth/logout` | выход |
| `GET` | `/api/me` | пользователь и квоты по моделям |
| `POST` | `/api/billing/purchase` | демо-активация тарифа |
| `POST` | `/api/scan` | multipart `file` + `model` |
| `GET` | `/api/scans?limit=` | история |
| `GET` | `/api/scans/{id}` | отчёт в JSON |
| `GET` | `/api/scans/{id}/report.html` | HTML-отчёт (`?download=1`) |
| `DELETE` | `/api/scans/{id}` | удалить отчёт |
| `POST` | `/api/admin/reset-usage` | сброс лимитов (нужен `X-Admin-Token`) |

## LDR

Паттерны сигнатур не лежат в исходниках открытым текстом: они хранятся как
`L("...")`/`B("...")` и декодируются при импорте. Заголовки и описания
правил остаются читаемыми, чтобы отчёт объяснял находку.

```bash
python3 tools/ldr_encode.py     # кодирует новые литералы
python3 tools/ldr_normalize.py  # склеивает вложенные обёртки
```

Ключ находится в `xsafety/scan/ldr.py`: это обфускация, а не шифрование.

## Безопасность

Подробности, модель угроз и список исправленных уязвимостей — в
[SECURITY.md](SECURITY.md). Коротко: файл не исполняется и не пишется на
диск, архивы распаковываются только в память с жёсткими лимитами, все
строки из файла экранируются, а лимиты и цены считаются на сервере.

## Ограничения

- Это статический анализ, а не антивирус: отсутствие находок не гарантирует
  безопасность.
- SQLite и троттлинг в памяти рассчитаны на один процесс.
- Оплата демонстрационная, платёжный провайдер не подключён.
