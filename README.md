# XSafety

Сканер файлов, который работает прямо в браузере. Файл не загружается на
сервер: он читается локально, проверяется сигнатурами и остаётся у вас.
Сайт — статическая сборка на **GitHub Pages**, аккаунты и история — в
**Firebase** (Authentication + Realtime Database).

- 127 сигнатур и структурные проверки: PE-заголовки, импорты, ZIP, JAR;
- 4 модели с разными наборами расширений;
- тарифы Default / Pro / Premium с суточными лимитами и ценами в гривнах;
- отчёты с серьёзностью находок, историей и экспортом в HTML;
- LDR-обфускация: паттерны не лежат в репозитории открытым текстом.

Живой сайт: **https://koteycagames.github.io/XSafety/**

> **Публикация.** GitHub Pages должен собирать сайт из ветки
> `arena/e4e4df9d-xsafety` (Settings → Pages → Source → Deploy from a branch

## Модели и расширения

| Модель | Расширения | Тарифы |
|---|---|---|
| **XSafety 1** | `.bat`, `.py` | Default, Pro, Premium |
| **XSafety 2** | + `.js`, `.ps1` | Pro, Premium |
| **XSafety 3 Lite** | + `.vbs`, `.hta`, `.dll`, `.zip` | Pro, Premium |
| **XSafety 3 Pro** | + `.exe`, `.jar` | Premium |

Модель вне тарифа не получает лимитов вообще: в интерфейсе она показана как
«нет лимитов» и не даёт сканировать, а счётчик для неё не создаётся.

## Суточные лимиты

Окно — календарные сутки UTC: счётчики обнуляются в 00:00 UTC.

| Тариф | XSafety 1 | XSafety 2 | 3 Lite | 3 Pro |
|---|---|---|---|---|
| **Default** | 10 запросов · 10 МБ | — | — | — |
| **Pro** | 20 · 30 МБ | 10 · 30 МБ | 1 · без лимита МБ | — |
| **Premium** | 30 · ∞ | 20 · ∞ | 15 · ∞ | 10 · ∞ |

Для тарифов без лимита МБ действует технический потолок файла — 64 МБ.

Скидка не хранится числом: она считается из пары «старая цена → новая»,
поэтому витрина и активация не могут разойтись. Покупка в демо-режиме:
тариф включается сразу, платёжный провайдер не подключён (см.
«Ограничения»).

## Как это устроено

```
index.html            SPA: вход, сканер, тарифы, история, админка
css/style.css         тёмная тема без внешних шрифтов
js/app.js             маршрутизация, вход, покупки, отчёты
js/admin.js           админ-панель: тарифы, лимиты, баны
js/firebase.js        Auth + Realtime Database
js/plans.js           лимиты и состояние моделей
js/core/engine.js     движок проверки файла
js/core/checks.js     структурные проверки (PE, текст, обфускация)
js/core/pe.js         разбор PE без исполнения
js/core/zip.js        ZIP/JAR в памяти, с лимитами
js/core/text.js       декодирование, строки, энтропия, редакция
js/core/ldr.js        декодер сигнатур
js/data/              сгенерированные правила и каталог тарифов
database.rules.json   правила Realtime Database
firebase.json         конфиг Hosting и правил (необязательно)
xsafety/              Python-эталон сигнатур и генератор данных
tools/build_web_data.py  генерация js/data из Python-реестра
tests/                pytest + Node-тесты (паритет и интерфейс)
```

Данные для сайта **не пишутся руками**: `tools/build_web_data.py`
выгружает Python-реестр `xsafety/scan/signatures/*` в `js/data/signatures/`,
кодируя все строки через LDR. Единственный источник правды — Python-модули,
а совпадение реализаций проверяет тест паритета.

### Обновить сигнатуры

```bash
# 1. правим правило в xsafety/scan/signatures/<ext>.py
python3 tools/ldr_encode.py        # кодирует новые литералы
python3 tools/ldr_normalize.py     # склеивает вложенные L()
python3 tools/build_web_data.py    # пересобирает js/data
python3 -m pytest -q               # паритет Python ↔ JS + интерфейс
git commit -am "sig: ..." && git push
```

GitHub Pages пересоберёт сайт автоматически (источник — эта ветка).

### Firebase

1. В проекте Firebase включены **Authentication → Email/Password** и
   **Realtime Database**.
2. Правила лежат в `database.rules.json`. Применить:
   ```bash
   firebase deploy --only database --project antivirus-1f569
   ```
   либо вставить файл в консоли Firebase → Realtime Database → Правила.
3. `js/firebase-config.js` содержит публичный веб-ключ — это нормально,
   доступ ограничивают правила и Auth. Адрес владельца задан там же
   (`ADMIN_EMAIL`) и продублирован в правилах.
4. Схема данных:
   ```
   users/{uid}      email, plan, planUntil, planOffer, banned, createdAt, usage, extra
   scans/{uid}/{id} filename, verdict, model, size, sha256, findings, scannedAt
   purchases/{uid}/{id} plan, offer, price, createdAt
   usage/{model}    count, bytes, period  (период — начало суток UTC)
   ```
5. Админ-панель доступна только `Koteyca@gmail.com`; чтобы сменить
   владельца, поменяйте email в `js/firebase-config.js` **и** в
   `database.rules.json`.

### Локальный запуск

Любой статический сервер из корня репозитория:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

ES-модули требуют HTTP, открывать `index.html` как файл нельзя.

### Серверная версия (необязательно)

В репозитории остаётся Python/FastAPI-реализация — она используется как
эталон сигнатур, генератор данных и набор тестов:

```bash
pip install -r requirements.txt
python3 -m xsafety     # http://localhost:8000
```

Сайт от неё не зависит: на GitHub Pages работает только статика.

## Тесты

```bash
pip install -r requirements-dev.txt
npm install --no-save jsdom     # для дымового теста интерфейса
python3 -m pytest -q            # 73 проверки
```

- `test_engine.py` — сигнатуры, PE, ZIP, PE-парсер;
- `test_api.py`, `test_security.py` — серверная версия и общая безопасность;
- `test_web_parity.py` — **паритет**: одни и те же образцы сканируются
  Python- и JS-движком, наборы `sig_id` обязаны совпасть;
- `test_web_ui.py` — app.js в jsdom: вход, 4 модели, 6 скидок, покупка,
  сканирование, история;
- `test_pricing.py`, `test_quota.py` — цены, скидки и лимиты.

## Ограничения

- Это статический анализ, а не антивирус: чистый вердикт не гарантирует
  безопасность.
- Лимиты считаются на клиенте. Правила базы запрещают уменьшать счётчик и
  менять чужой профиль, но настойчивый пользователь может обойти квоту
  через консоль браузера — для жёсткого контроля нужны Cloud Functions.
- Демо-оплата: тариф активируется без списания денег.
- RAR/7z не распаковываются, проверяется только сигнатура формата.
- LDR — обфускация, а не шифрование.
